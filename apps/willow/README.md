# Willow

<!-- pmm-badge -->
![PMM Maturity](../../.p31/badges/willow.svg)
<!-- /pmm-badge -->

Child-friendly companion app — games, mood tracking, drawing, family mesh.

## Commands
| Script | What it does |
|--------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Build for production |
| `npm run test` | Run tests with coverage |
| `npm run deploy` | Deploy to Cloudflare Pages |

## Routes
- `GET /health` — liveness (via `public/_worker.js`)
- Vite dev server on localhost:5173
