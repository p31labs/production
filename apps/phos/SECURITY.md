# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅ |
| < latest | ❌ |

## Reporting a Vulnerability

P31 Labs takes security seriously. If you discover a vulnerability:

1. **Do not** open a public GitHub issue
2. Email: willyj1587@gmail.com
3. Include a description, steps to reproduce, and suggested fix if applicable

You can expect acknowledgment within 48 hours and a detailed response within 5 business days.

## Preferred Encryption

PGP key available on request. For non-sensitive reports, email is sufficient.

## Bug Bounty

This project does not currently operate a bug bounty program. Security researchers are credited in our security hall of fame.
