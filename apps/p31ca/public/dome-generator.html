phosphorus31.org

Dome data generator

Create a JSON file for p31ca.org/dome. Each node gets a triangular face on the geodesic (up to 320 faces with the current mesh). Axes a–d are weights toward four directions (Body / Mesh / Forge / Shield) — use them to spread items in the dome. Edges are optional links between nodes for the detail panel.

Dataset title

Nodes

Each node: unique id, label, axis weights a,b,c,d (0–4), state (e.g. active, deployed, countdown, complete, missing), bus (vital, ac, dc), optional notes.

Edges

Triple: [fromId, toId, relationLabel] — both ids must exist in nodes above.
