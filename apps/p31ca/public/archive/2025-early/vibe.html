Run the PiP CLI right now

The substrate already exists. Ephemeralization: one HTML file, three URLs, zero duplication.

Operator runbook Read the canonical 6-move loop: docs/operator/BOOT-UP-AND-USE.md. It is the same doc the substrate serves as the boot-up view slug, so the loop is self-describing once you are inside.

  1. On your operator machine, run npm run command-center from the bonding-soup repo root.
  2. Open http://127.0.0.1:3131/vibe in your browser (alias of /term).
  3. Pick a PHOS persona from the dropdown, or switch to cmd mode and type a whitelisted action like npm run doctor.

Source of truth: command-center-terminal.html in bonding-soup. Served from :3131/term, :3131/terminal, and :3131/vibe. New URL in front of an existing service — no new code, no new attack surface.
