## P1 remediation performed
1. `font-weight` normalization → token ladder (`--p31-font-weight-body:400`, `-emphasis:500`), all 600/700/800 literals mapped to 500-equivalent emphasis.
2. `prefers-reduced-motion` guard added to `styles/base.css`.
3. Ghosting guard: decorative/infinite animations pause via `[data-hidden="true"]` + `.is-offscreen` selectors.
