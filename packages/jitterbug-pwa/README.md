# @p31ca/jitterbug-pwa

Progressive Web App for capturing brain dumps in the Jitterbug Ambient Exocortex. Installable on iPhone, Android, and Chromebook.

## What is Jitterbug?

Jitterbug is a recursive brain-dump orchestration system. Instead of forcing you to organize thoughts before you have them, it captures raw unstructured input, then auto-decomposes into actionable tasks up to 5 levels deep.

The PWA is the capture layer. It runs entirely in the browser (or as an installed app) and talks to the Jitterbug API Worker over HTTPS.

## Features

- **Installable PWA** — add to home screen on iOS, Android, and desktop
- **Offline-first drafts** — auto-saves to localStorage with retry on reconnect
- **Three views** — Capture, History, and Status Dashboard
- **Recursive orchestration** — depth-first, breadth-first, or layer-sequential batch strategies
- **Visual Translator** — context-isolated narrative views for four audiences: Poet, Judge, Funder, Physicist
- **Kill switch** — partition recovery endpoint for emergency data seizure protection
- **SSE streaming** — real-time status updates during orchestration
- **Tailwind CSS v4** — styled with dark-warm theme

```

Or connect the `software/packages/jitterbug-pwa` repository to a Cloudflare Pages project for Git-based deploys.

Set `VITE_API_URL` to your Jitterbug API endpoint (e.g., `https://jitterbug-api.trimtab-signal.workers.dev`).

```

## PWA Details

- Manifest: `manifest.webmanifest`
- Service worker: auto-generated by `vite-plugin-pwa`
- Offline cache: static assets + recently viewed brain dumps
- Install prompt: triggered by browser on supported platforms

## Architecture

The app is a single-page React app with three views:

1. **Capture** — form for new brain dumps
2. **History** — list of previous submissions
3. **Status** — live orchestration dashboard for a selected brain dump

State management is local (useState + custom hooks). Draft persistence uses localStorage. Production status tracking uses SSE and the StatusDashboard component.
