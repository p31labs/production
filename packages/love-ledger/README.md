**L.O.V.E. — Ledger of Ontological Volume and Entropy**

Economic layer for the P31 assistive technology ecosystem. Tracks care transactions, trust events, and resource allocation across the K₄ mesh.

## Install
```bash
npm install @p31ca/love-ledger
```

## Build
```bash
npm run build
```

## Test
```bash
npm run test
```

## Scripts
| Command | Purpose |
|---------|---------|
| `npm test` | Run vitest suite |
| `npm run build` | Compile TypeScript |
| `npm run clean` | Remove dist/ |
