# @p31ca/love-ledger — Deployment

## Build
```bash
npm run clean && npm run build
```

## Publish (when ready)
```bash
npm publish
```

## Post-publish verification
```bash
npm view @p31ca/love-ledger version
```

## Consumer install
```bash
npm install @p31ca/love-ledger
```

## Runbook
- Tests: `npm test`
- Build: `npm run build`
- Clean: `npm run clean`
