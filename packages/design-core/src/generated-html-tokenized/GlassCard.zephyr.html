P31 × Zephyr — GlassCard POC

Proof-of-concept: Zephyr web component styled with P31-Q design tokens. Pure CSS interactions. Agent-controllable via MCP.

Interactive Component

GlassCard

This modal is a Zephyr <z-modal> component styled entirely with P31-Q design tokens. No runtime JavaScript is required for the glass effect, border, shadow, or transitions.

Agent API: An AI agent can open this modal with: Zephyr.agent.act('#glass-card-modal', 'open')
