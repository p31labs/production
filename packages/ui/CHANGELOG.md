# @p31ca/ui — Changelog

## 1.3.0 — 2026-07-19

### Added
- `@p31ca/ui/layout` subpath export — all layout components now importable from a
  single entrypoint:
  `import { Section, PageHeader, StatTiles, CardGrid } from '@p31ca/ui/layout';`

### Exports
- `"./layout": "./src/layout/index.ts"` (registered in `package.json`).

---

## 1.2.0

Added layout suite: `Section`, `PageHeader`, `StatTiles`, `CardGrid`.

## 1.1.0

Added chrome components: `SiteNav`, `P31Chrome`, `CrisisIsland`, `Footer`,
`GlassCard`, `GlowButton`, `SkipLink`, `CompanionPanel`, and the
`SovereigntyStrip` / `SpoonDial` surfaces.
