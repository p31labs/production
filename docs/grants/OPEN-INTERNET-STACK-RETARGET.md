## Retarget candidates by Open Internet Stack theme (once announced)

The three new programmes are not yet specified. Based on NGI Zero's track record,
likely themes and the best-fit parked proposal for each:

1. **Commons / open-source infrastructure** → K4-Mesh-Core (€35K) or the €15K
   k4 bonding-soup variant. K₄ is a sovereign P2P mesh protocol — a natural
   "open internet commons" building block.
2. **Hosting / edge / self-sovereignty** → P31 Portal supplement (€5K, WebMCP +
   A2UI + spoon-aware sovereign portal). Fits a hosting/edge programme.
3. **Security / trust** → Security audit ask (€15K, Trail of Bits / NCC Group /
   Cure53 / Doyensec / Open Privacy Research Society) if a security-track
   programme appears.
