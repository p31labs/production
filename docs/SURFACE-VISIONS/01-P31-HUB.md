# P31 Hub — Design Vision

## Identity

- **Name:** P31 Labs Technical Hub
- **URL:** `p31ca.org`
- **Tagline:** "Open-Source Assistive Technology."
- **Audience:** Developers, operators, technical contributors
- **Purpose:** Fleet status dashboard, product registry, ops tools, research publications, technical documentation
- **EIN:** 42-1888158 (P31 Labs, Inc.)

---

## Layout System

- **Max width:** `max-w-6xl` (1152px) centered
- **Page padding:** `px-6` (24px) horizontal, `pb-16` (64px) bottom
- **Grid:** 1-column mobile → 2-3 column responsive (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`)
- **Gutters:** `gap-4` (16px) between cards, `gap-6` (24px) between sections
- **Two layout modes:**
  - `BaseLayout` — landing page (this document)
  - `AppShell` — inner pages (sops, products, research sub-pages)

## Glass/Visual Language

- **Glass blur:** `backdrop-filter: blur(12px)` (`blur-md` in Tailwind)
- **Border radius:** `12px` (`rounded-xl`) for cards, `8px` (`rounded-lg`) for buttons/badges
- **Surface opacity:** `rgba(255,255,255,0.04)` base, `rgba(255,255,255,0.06)` hover
- **Border opacity:** `rgba(255,255,255,0.06)` base, `rgba(255,255,255,0.10)` hover
- **Shadow:** Soft, `0 8px 32px rgba(0,0,0,0.15)` base
- **Gradient:** None on cards; hero has subtle quantum-cyan glow from K4 SVG

---

## Motion

- **Imported:** `@p31ca/design-system/motion` (6-tier spoon-aware)
- **K4 SVG animations:** Inline `<animate>` elements — stroke-dasharray cycling (3-5s), orbital rotation (12-24s), vertex pulsing (1.5-2.5s)
- **Card transitions:** `all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`
- **Hover lift:** `translateY(-2px)` on cards
- **Status dot:** `box-shadow` glow pulse for online indicators

## Content Sections (Landing Page Anatomy)

1. **Navbar** — sticky glass, logo + links + donate CTA

3. **Ecosystem Bridge** — 3-layer explanation (nonprofit → hub → edge)
4. **Fleet Status Bar** — live worker health grid
5. **Live Deployments** — 3-column grid of production cards (green dot)
6. **Production Suite** — 3-column grid of edge apps (violet "Edge" badge)
7. **In Development** — 3-column grid of prototypes (amber badge)
8. **Research Tools** — 3-column grid of frameworks (fuchsia badge)
9. **Publications** — 2-column grid of DOI papers (cyan badge)
10. **Stats Bar** — 4-metric summary (deployments, tests, papers, hallucinations)
11. **Footer** — `SharedFooter` component

## Interactive States

- **Card hover:** border lightens, background opacity increases, card lifts 2px, title color → hubRose
- **Link hover:** color transitions (cyan → cyan-300, rose → rose-300)
- **Button hover:** brightness-110, slight lift
- **Status dots:** green glow (`box-shadow: 0 0 6px rgba(52,211,153,0.6)`), red glow for errors
- **Fleet check:** Async fetch from `command-center.p31ca.org/api/status`, updates dots in-place

## Accessibility

- Skip link: `<a href="#main-content">`
- Semantic landmarks: `<nav>`, `<main>`, `<section>` with `aria-labelledby`
- Fleet status uses `id` attributes for JS updates (no ARIA live region — consider adding)
- Card links use `style="text-decoration:none"` for visual consistency
- Color contrast: `text-white/55` on `#0A0A0F` ≈ 7.5:1 (passes AAA)

## Gemini Prompt Notes

- The Hub is a **developer-facing** dashboard — prioritize information density over ambient atmosphere
- The rose accent (`#E8636F`) is **intentionally different** from the quantum palette — this is the Hub's brand identity
- The K4 tetrahedron SVG is 160px (smaller than other surfaces — it's a logo, not a hero)
- Fleet status section fetches live data from command-center API — template should include the fetch pattern
- Cards use `glass-panel` class, NOT `glass-card` — slightly different styling
- Two token systems exist: `hub-tokens` for landing pages, `p31-qmu-tokens` for inner app pages — keep them separate
- Footer is a shared component (`SharedFooter.astro`) — don't inline it
