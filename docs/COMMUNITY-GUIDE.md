# Community Guide — P31 Labs

**CWP:** CWP-2026-047 (Growth Frontier), Phase 4
**Status:** Proposed (not yet an established community — this is the intended model)

P31 builds **open-source, sovereign, neuroinclusive, post-quantum assistive
technology** for neurodivergent families. We want a community that can sustain
and grow the stack beyond the initial NGI funding.

---

## How to get involved

- **Code:** see `CONTRIBUTING.md` — local setup, tests, PR process.
- **Chat:** Discord + Matrix (bridge) — `#p31-dev`, `#p31-care` (links TBD).
- **Meetings:** bi-weekly community call (calendar TBD); notes posted to the repo.
- **Bounties:** NGI-funded + Open Source grants fund specific issues (label `bounty`).

## Governance (proposed)

| Body | Role | Composition |
|------|------|--------------|
| **Technical Steering Committee (TSC)** | Strategic direction, releases | Core maintainers + community-elected seat |
| **Maintainers** | Review + merge, issue triage | Proven contributors (≥3 merged PRs) |
| **Contributors** | Everyone with a merged PR | — |

Decisions: lazy consensus; contested items escalate to the TSC (2/3 majority).

## Communities of practice

- **Care attestation** — pilots, families, care orgs.
- **Cryptography** — PQC (ML-DSA-65, X-Wing KEM), SD-JWT VC, DID.
- **Federation** — ActivityPub, FEP-8b32, BadgeFed, EUDI interop.
- **Neuroinclusive UX** — `data-spoons`, glassmorphism, crisis mode, WCAG 2.2.

## Events (proposed)

- FOSDEM 2027 talk (submitted).
- NGI Forum presentation.
- Local care-tech hackathons (Q4 2026).
