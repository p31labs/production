# Research Notes — Neurodivergent Participatory Design & Usability Testing

Sources pulled for the template package (deep web, Jul 2026).

## W3C WAI — Involving Users in Web Projects (2020)
https://www.w3.org/WAI/planning/involving-users/
- Involve users **early and throughout**; accessibility is about UX, not just a checklist.
- **Get a range of users** — disability, age, AT experience all vary widely.
- **Caution:** input from one person ≠ all people with that disability. Avoid over-generalising.
- Working with users: informed consent, free to stop anytime, respect time, **appropriate compensation**.
- Combine user involvement with **WCAG** conformance for full coverage.

## Nielsen Norman Group — Usability Testing 101 (Moran, 2019)
https://www.nngroup.com/articles/usability-testing-101/
- Core elements: **facilitator, tasks, participant**.
- **Think-aloud** method to surface behavior + motivation.
- Qualitative studies: **5 participants** surface most common issues for a single user group.
- Remote: **moderated** (screen-share, live) vs **unmoderated** (async, self-run).
- Task wording matters — avoid priming / leading questions.
- Informed consent required (see NN/g "Obtaining Consent for User Research").
