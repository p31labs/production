# Phase 3 — MCP Tools & Agentic Workflows Script

**Goal:** Validate the 46 MCP tools in real daily workflows; measure adoption + energy impact.
**Format:** 2-week diary study (5–10), 1:1 interviews (5–7), community session (8–12).

## A. Diary study (2 weeks)
- Day 0 onboarding (30 min): install/connect P31 MCP tools; pick 2–3 to try.
- Daily (async, 2 min): "Spoons now? Did a tool help? What did you do?" via voice memo or form.
- Day 7 check-in (15 min): surface friction early.
- Day 14: short wrap survey (effort 1–5, retained yes/no, top missing tool).

## B. 1:1 interview (45 min)
- "Walk me through a real task the tool helped or failed."
- "Where did it waste your energy instead of saving it?" (key spoon metric)
- "What tool is missing for your life?"
- Capture feature gaps → Phase 4 backlog.

## C. Community feedback session (60 min, group)
- Round: one win, one pain.
- Brainstorm: "If P31 built one new MCP tool for neurodivergent users, what?"
- Collect themes.

## Metrics
- **Adoption:** tools tried / retained after 2 weeks.
- **Energy:** self-reported spoon usage before/after using tools (diary avg).
- **Efficiency:** time to complete a typical task with vs. without tools (interview estimate).
- **Gaps:** ranked missing-tool list.

## Spoon-aware notes
- Diary prompts are 2 min max; skip days are fine.
- Interviews reschedule freely; no-show = send payment anyway if they did onboarding.
- Offer text or voice for every prompt.
