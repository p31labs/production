# Phase 1 — Arcade Game Usability Script (45–60 min, remote/in-person)

**Goal:** Validate spoon-aware difficulty (`data-spoons`), accessibility, UX.
**Metrics:** spoon-fit (qual), error rate, task completion, cognitive load (1–5), WCAG 2.1 AA spot checks.

## 0. Setup (5 min)
- Confirm consent on file; screen recording only if agreed.
- Spoon check-in: "On a scale of 1–5 spoons, where are you right now?" Adapt pace to answer.

## 1. Warm-up (5 min)
- "Talk me through the last game or app you enjoyed. What made it easy or hard?"
- No evaluation — build rapport.

## 2. Guided play (20–30 min)
Rotate through **2 games** (pick from Gridiron, Bashball, Strategy Board per participant interest):
- "Play as you normally would. Think aloud if you can — if not, that's fine."
- Moderator silently notes: confusion points, where they hesitate, any frustration.
- Midway: "How's your energy now (1–5)?" If dropped ≥2, offer a break or shorter second game.
- If available, demonstrate the spoon slider / difficulty change and ask: "Does the game feel easier or harder now? Does that match how you feel?"

## 3. WCAG 2.1 AA spot checks (10 min)
- Keyboard only: can they reach and activate key controls? Note focus visibility.
- Contrast: any text hard to read? (mention we target ≥4.5:1)
- Screen reader (if participant uses one): any unlabeled buttons?
- Record each as pass/fail + note.

## 4. Close (5 min)
- "What's one thing you'd change?" / "What surprised you?"
- Confirm payment method; thank them.

## Red flags → escalate
- Participant distressed → stop, offer break, no pressure to continue.
- Repeated unexplained errors → likely UX bug, log exact steps for dev fix.
