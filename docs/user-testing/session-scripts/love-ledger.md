# Phase 2 — LOVE Ledger & Cognitive Passport Script

**Goal:** Validate privacy, trust, usability; gather co-design input; check eIDAS 2.0 alignment.
**Three formats:** co-design workshop (90 min), prototype test (45 min), privacy interview (30 min). Run workshop + tests with overlap where possible.

## A. Co-design workshop (90 min, 4–6 ppl)
1. Spoon check-in + consent (5 min).
2. Concept walkthrough (15 min): "The LOVE Ledger records care work — like helping with a task — as a private, timestamped credit. No bank, no surveillance." Show a mock entry.
3. Whiteboard (Miro): "Design the care-credit screen you'd trust." Prompt: what must be visible? what must stay private? (20 min)
4. Audit-log view: "If a court or care coordinator needed proof care happened, what should they see?" (20 min)
5. Dot-vote top 3 features; capture quotes. (10 min)

## B. Prototype test (45 min, 6–8 ppl, 1:1)
- Task 1: "Create a care credit for a task you did this week." (observe steps, errors)
- Task 2: "Open the audit log and verify a timestamp." (comprehension check)
- Task 3: "Show me what you'd hide from everyone else." (privacy mental model)
- Ask: "Explain the ledger in your own words." (comprehension metric)

## C. Privacy & trust interview (30 min, 8–10 ppl)
- "What would make you trust this? What would make you delete it?"
- "Who, if anyone, should ever see your ledger?"
- Likert 1–5: data safety / transparency / control.

## eIDAS 2.0 alignment check (log for compliance evidence)
- [ ] Append-only, timestamped entries demonstrated
- [ ] User can export/verify without P31 custody
- [ ] Audit view separable from personal content
- Note how this maps to EUDI Wallet auditability requirement (Dec 2026 member-state deadline).

## Deliverables
- LOVE ledger usability report + privacy/trust framework + co-design artifacts (Miro export, votes).
