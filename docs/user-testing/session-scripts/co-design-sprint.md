# Phase 4 — Co-Design Sprint Script

**Goal:** Generate new features directly with users → Q4 2026 – Q1 2027 roadmap.
**Format:** ideation workshop (90 min) + prototyping (120 min) + async feedback loop.

## A. Ideation workshop (90 min, 6–8 ppl)
1. Spoon check-in + consent (5 min).
2. Recap learnings from Phases 1–3 (5 min): "Here's what you told us. What did we miss?"
3. Brainstorm (40 min): "New arcade game? New MCP tool? New ledger feature?" Use silent writing → round-robin → cluster.
4. Dot-vote top 5 ideas (10 min).

## B. Prototyping session (120 min, 4–6 ppl)
- Split into 2 groups; each sketches a low-fidelity prototype of a top-voted idea (paper/Figma).
- 5-min pitches; whole-group vote on priority (10 min).
- Capture: flow, spoon-aware considerations, accessibility must-haves.

## C. Async feedback loop (1 week)
- Post prototypes in the community channel.
- Participants leave written/audio feedback (no deadline pressure).
- Moderator synthesizes into roadmap draft.

## Output
- Co-designed feature roadmap with **≥5 new features**, each with:
  - one-line description
  - target user + spoon scenario
  - accessibility note
  - suggested phase (Q4 2026 / Q1 2027)

Feed into `FINAL-REPORT.md` and the public case study.
