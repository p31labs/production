# Incentives & Compensation — Spoon-Aware

**Budget:** ~$1,300 total (20 × ~$50 avg + bonuses). Keep it frictionless.

## Amounts
- Standard session: **$25–50** (scale by length: 30 min = $25, 60 min = $40, 90 min = $50).
- Multi-session bonus: **+$15** for completing ≥2 sessions.
- Co-design sprint: counts as one session at the higher rate.

## Payment methods (offer all; let participant choose)
- **PayPal** (preferred, instant, low friction)
- **Gift card:** Amazon / Visa / prepaid (email delivery)
- **LOVE Ledger test credit** (opt-in only, for ledger-phase participants — doubles as a live test of the product)

## Spoon-aware rules
- Send payment **within 48 hours** of session completion — no "end of month" batching.
- One link/email, no account creation required to redeem gift cards.
- No IRS/W-9 forms for these amounts; if a participant exceeds $600 cumulatively, pause and consult the 501(c)(3) operator before issuing a form.
- If a participant withdraws mid-session, pay prorated for time completed.
