**Owner:** William R. Johnson · **Window:** July 10 – Oct 15, 2026

## Spoon-aware protocol (applies to every session)
- Sessions are **short and modular**; participants may pause, reschedule, or leave at any time.
- Start every session with a **spoon check-in** (1–5); adapt length/intensity to the number given.
- Offer **remote / in-person / async** formats; never require camera-on.
- Compensation is sent **within 48h**, no tax-form burden for small amounts (see `incentives.md`).
- Plain-language everything; offer text, audio, and video formats for all materials.
