`audit-cross-domain-reconcile.mjs` enumerated domain chains from the
filesystem (`domains/*/`), while `govern reconcile` mirrored only the
enterprise spec's domain list. The declared-not-governed family domain

not part of the enterprise timeline until governed, so it can never be
reconciled.

(the source of truth), mirroring `govern reconcile` exactly. Family's
blocks are no longer orphans; the audit domain audits at baseline 0.
