# P31-Wide Glossary

Terms that are P31-wide, shared across the ecosystem (not engine-specific —
engine terms live in [conventions.md](conventions.md)). Definitions here are
authoritative; if a term is used differently elsewhere, this file wins.

| Term | Definition |
|---|---|
| **Tetrahedron Protocol** | The P31 published thesis (Zenodo 2026-02-13) that the regular tetrahedron (K₄, complete graph) is a universal stability archetype across quantum information, structural rigidity (Maxwell E ≥ 3V − 6), quantum biology (Posner molecule), and network topology. The engine's SIC-POVM truth layer and two nested tetrahedra operationalize it. |
| **Loom** | The canon's append-only event log. The training substrate; every propose→approve/reject is a labeled example. v1.2 added `chat.artifact.generated` with optional `screenshotRef` / `screenshotRef2`. |
| **Canon** | `@p31ca/canon` — the family-first, agent-native design system: typed tokens, contracts, DTCG export, DESIGN.md. |
| **LOVE** | The P31 value token (Proof of Care) — LOVE = round(complexity × tier × category), clamped 1–50. |
| **Spoons** | Cognitive capacity units (Fisher-Escolà Q distribution). The UI adapts to spoon level. |
| **Progressive disclosure** | Revealing UI by metabolic capacity; Layer 0 = fullscreen somatic regulation. |
| **Cognitive Prosthetic** | P31's founding concept (Genesis Whitepaper): local-first, privacy-preserving environments that protect neurodivergent executive function from systemic decoherence. |
| **SOULSAFE** | P31 Paper XIX: high-reliability human–AI QA — the Triad of Cognition (separation of concerns), Red Board Diagnostics, Objective Quality Evidence. The engine's "separate vertices, never one mind" follows from it. |
| **Posner molecule** | Ca₉(PO₄)₆ — Fisher's hypothesized biological qubit; the phosphate tetrahedron is the structural metaphor at the heart of the Tetrahedron Protocol. |
