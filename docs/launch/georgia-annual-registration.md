# Georgia Annual Registration Filing Guide
**Deadline:** July 2, 2026
**Entity:** P31 Labs, Inc. (Georgia Domestic Nonprofit Corporation)
**EIN:** 42-1888158

---

## OVERVIEW

Georgia domestic nonprofit corporations must file an annual registration with the Georgia Secretary of State each year. The filing maintains the corporation's active status.

## FORM

- **Form:** C-100
- **Fee:** $30
- **Portal:** sos.ga.gov

## STEP-BY-STEP

1. Go to https://sos.ga.gov/index.php/corporations/annual_registration
2. Log in or create an account
3. Search for entity: **P31 Labs, Inc.**
4. Verify entity number and name match records
5. Complete the annual registration form:
   - Principal office address
   - Registered agent info
   - Principal officer / director info
6. Pay $30 fee via credit card or eCheck
7. Save confirmation / receipt
